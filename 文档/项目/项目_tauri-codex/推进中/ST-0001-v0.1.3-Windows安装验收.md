## 固定边界

被测对象是 GitHub Release `v0.1.3` 的 `tauri-codex_1.0.0_x64-setup.exe`，本地已下载并再次计算 SHA-256，结果为候选标识中的摘要。环境是 Windows 10 22H2 x64 的当前用户环境；已有 `0.1.1` 安装登记和 `%APPDATA%\com.tauri.codex` 用户数据必须原样保留。用户明确要求以当前环境作为验收环境，未覆盖的机器或平台差异由用户提交 Issue。

安装器未签名，作为本次可见残余风险记录，不绕过 Windows 安全提示。

## 断言

1. 经管理员确认后，线上安装器在原安装位置完成就地安装或修复，不要求卸载，也不删除用户数据。
2. 安装登记显示 `tauri-codex`，桌面快捷方式存在且目标是稳定 Launcher `tauri-codex.exe`。
3. 从已安装 Launcher 启动，首个窗口不空白，展示真实 Bootstrap、组件和下载字节状态；组件准备完成后启动 Manager `0.1.3`。
4. Manager 显示 Codex `0.147.0`，设置页有“检查更新”入口；安装数据目录具有可运行的 `releases/current`，并记录 staging/previous 的实际状态。

## 进入、退出与阻断

进入条件已满足：候选公开可读、大小和 SHA-256 与 GitHub API 一致，Release 闭包已验证。当前阻断是 per-machine NSIS 安装需要 Windows UAC 管理员确认；自动启动被系统取消，确认旧 `0.1.1` 安装、用户数据和桌面状态均未变化。

管理员确认后继续执行上述断言。任一产品断言失败时停止本计划，不修改源码或候选；需要修复时等待用户授权独立 Development。不会在本计划中执行全新机器、Windows 11、Windows 10 以外版本、损坏包或回滚故障注入场景。
