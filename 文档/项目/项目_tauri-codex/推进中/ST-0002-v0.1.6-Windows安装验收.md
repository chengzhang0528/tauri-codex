## 固定边界

被测对象是公开 GitHub Release `v0.1.6` 的 `tauri-codex_1.0.2_x64-setup.exe`，已下载到本机应用安装包目录并核对为 13172716 字节，SHA-256 与 Candidate 一致。环境是 Windows 10 22H2 x64 当前用户；已有 `1.0.1` 安装登记、桌面快捷方式和 `%APPDATA%\com.tauri.codex` 用户数据必须保留。安装器未签名，作为残余风险记录，不绕过 Windows 安全提示。

## 断言

1. 经用户确认 Windows UAC 后，Installer 完成 `1.0.1` 到 `1.0.2` 的就地升级，不要求卸载且不删除用户数据。
2. 安装登记显示 `1.0.2`，公共桌面快捷方式仍存在并指向稳定 Launcher。
3. Launcher 复用或准备线上组件后不再出现 `拒绝访问。(os error 5)`，生成 `releases/0.1.6` 与原子 `releases/current.json`，其 current 为 `0.1.6`。
4. 由安装路径 Launcher 启动 Manager `0.1.6`；Manager 使用 Codex `0.147.0`，设置页存在“检查更新”入口且页面不空白、不重叠。

## 停止条件

任一产品断言失败时停止，不修改源码或候选；保留最小现场供独立 Development。不会在本计划中覆盖全新机器、Windows 11、其他 Windows 版本、损坏包、签名或故障注入场景，未覆盖环境由用户提交 Issue。
